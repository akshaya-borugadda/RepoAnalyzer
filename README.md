# 🚀 RepoAnalyzer

### AI-Powered Repository Intelligence Platform

RepoAnalyzer is an AI-powered platform that helps developers understand GitHub repositories in seconds. By simply providing a repository URL, the system automatically analyzes the codebase, identifies technologies, highlights important files, detects potential dead code, generates architecture insights, and allows users to chat with the repository using AI.

---

## ✨ Key Features

### 🔍 Repository Analysis

* Analyze public GitHub repositories from a URL
* Generate complete file and folder structures
* Extract repository statistics and insights

### 🛠️ Tech Stack Detection

Automatically identifies technologies such as:

* React
* Next.js
* Node.js
* Express.js
* FastAPI
* Flask
* Django
* PostgreSQL
* MongoDB
* MySQL
* Docker

### 📄 AI Project Summary

* Understand repository purpose instantly
* Generate project overviews automatically
* Identify major components and architecture

### 📌 Important File Detection

Highlights:

* Entry points
* Configuration files
* API routes
* Database connections
* Core application files

### 🧹 Dead Code Detection

Identifies potentially:

* Unused files
* Unused components
* Orphaned modules
* Redundant routes

### 🏗️ Architecture Insights

* Repository structure visualization
* Dependency relationships
* Architecture flow generation
* Mermaid diagram support

### 🤖 AI Repository Assistant

Ask questions like:

* Which file handles authentication?
* Where is the database connection?
* Explain the project architecture.
* Which files may be unused?
* What does this repository do?

## 🚀 Getting Started

### Clone Repository

```bash
git clone https://github.com/akshaya-borugadda/RepoAnalyzer.git
cd RepoAnalyzer
```

### Backend Setup

```bash
cd backend
pip install -r requirements.txt
uvicorn app.main:app --reload
```

Backend URL:

```text
http://127.0.0.1:8000
```

### Frontend Setup

```bash
cd frontend
npm install
npm run dev
```

Frontend URL:

```text
http://localhost:5173
```
