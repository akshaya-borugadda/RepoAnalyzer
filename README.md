\# 🚀 RepoAnalyzer



\*\*AI-Powered Repository Intelligence Platform\*\*



RepoAnalyzer helps developers understand any GitHub repository in seconds. Simply provide a repository URL and RepoAnalyzer automatically analyzes the codebase, detects the technology stack, identifies important files, highlights potential dead code, generates architecture insights, and enables AI-powered conversations about the repository.



\---



\## ✨ Features



\### 🔍 Repository Analysis



\* Analyze public GitHub repositories from a URL.

\* Generate complete file and folder structures.

\* Calculate file and language statistics.



\### 🛠️ Technology Stack Detection



Automatically detects:



\* React

\* Next.js

\* Node.js

\* Express.js

\* FastAPI

\* Flask

\* Django

\* PostgreSQL

\* MySQL

\* MongoDB

\* Docker



\### 📄 Intelligent Project Summary



\* Understand what a repository does.

\* Identify key technologies and architecture.

\* Generate project overviews automatically.



\### 📌 Important File Identification



Highlights:



\* Entry points

\* Configuration files

\* API routes

\* Database-related files

\* Core application logic



\### 🧹 Dead File Detection



Detects potentially:



\* Unused files

\* Unused components

\* Unused routes

\* Orphaned modules



\### 🌐 Architecture Insights



\* Repository structure visualization

\* Architecture flow generation

\* Dependency relationships

\* Knowledge graph generation



\### 🤖 AI Repository Assistant



Ask questions such as:



\* Which file handles authentication?

\* Which file connects to the database?

\* Explain the project architecture.

\* Which files are potentially unused?

\* What does this repository do?

\* Which file contains API routes?

\## 🚀 Getting Started



\### Clone Repository



```bash

git clone https://github.com/akshaya-borugadda/RepoAnalyzer.git

cd RepoAnalyzer

```



\### Backend Setup



```bash

cd backend



pip install -r requirements.txt



uvicorn app.main:app --reload

```



Backend:



```text

http://127.0.0.1:8000

```



\### Frontend Setup



```bash

cd frontend



npm install



npm run dev

```



Frontend:



```text

http://localhost:5173

```
